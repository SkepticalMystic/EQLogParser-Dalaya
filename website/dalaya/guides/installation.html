Installation

System requirements, dependencies, and first launch.

Requirements

  • Windows 10 or 11, 64-bit
  • .NET 8 Desktop Runtime (x64) — see Step 1
  • EverQuest with logging enabled — see Step 2
  • Windowed mode in EverQuest if you plan to use overlays (damage meter, timer bars)

Step 1 — Install .NET 8

EQLogParser-Dalaya requires the .NET 8 Desktop Runtime from Microsoft. If you already have it installed (for example, because you have run another .NET 8 app), you can skip this step.

Download the .NET 8 Desktop Runtime (x64) from Microsoft and run the installer:

https://dotnet.microsoft.com/en-us/download/dotnet/8.0

On that page, look for Desktop Runtime under the Windows column and download the x64 installer. Run it and follow the prompts — no configuration is needed.

Step 2 — Enable EverQuest logging

EQLogParser reads your EverQuest log file in real time. Logging is off by default and must be enabled each session, or set permanently in your EQ config.

To enable for the current session: type /log on in the EverQuest chat window. You will see a confirmation message. Logging stays active until you type /log off or log out.

To enable permanently: open eqclient.ini in your EverQuest folder and set Log=TRUE. This enables logging automatically every time EQ launches.

Your log file is written to the Logs subfolder of your EverQuest installation:

[EQ folder]\Logs\eqlog_CharacterName_dalaya.txt

The dalaya portion of the filename is the server identifier for the Dalaya server. For example, a character named Kateila would have a log file at: 

C:\Sony\EverQuest\Logs\eqlog_Kateila_dalaya.txt

Log in to your character before proceeding to Step 4 so the log file already exists on disk when you select it in the parser.

Step 3 — Download and install EQLogParser-Dalaya

  1. Go to the latest release on GitHub
  2. Under Assets, download EQLogParser-install-X.Y.Z.exe
  3. Run the installer

Because the installer is not signed with a commercial certificate, Windows may show a "Windows protected your PC" SmartScreen warning. Click More info and then Run anyway to proceed. The installer places the application in C:\Program Files\EQLogParser-Dalaya\ and creates a desktop shortcut.

Step 4 — First launch

  1. Launch EQLogParser-Dalaya from the desktop shortcut or Start menu
  2. Click the folder icon in the top-left of the toolbar to open the log file picker
  3. Navigate to your EverQuest Logs folder and select the log file for your character (eqlog_CharacterName_dalaya.txt)
  4. The title bar updates with your character name and the parser begins reading the log in real time. Combat events from that point forward will be captured automatically.

To catch fights you were already in before opening the parser, use File → Open Log File and select the same log. This reads the full file from the beginning rather than tailing it live.

Updates

EQLogParser-Dalaya checks for new releases automatically on startup. When an update is available, a notification appears in the toolbar. Download the new installer from the releases page and run it over the existing installation — settings and trigger configurations are preserved.
