Trigger Variables

Special codes used in trigger Pattern and message fields.

Trigger variables are codes you embed in trigger fields to capture values from the log line or to insert dynamic information into your alerts. They work in both Pattern fields (to capture) and in output fields like Text to Speak, Text to Display, and Alternate Timer Name (to display the captured value).

Variables are case-insensitive: {c} and {C} behave identically. For indexed variables like {Sx} or {Nx}, x is any digit from 0 to 9, allowing multiple captures in the same trigger.

Modifiers

Captured values can be transformed for display using dot-modifiers. These only work in output fields, not in Pattern fields.

  • {S1.capitalize} — capitalizes the first letter
  • {N.number} — formats the number with thousands separators (e.g. 1,250)
  • {S1.upper} — converts to uppercase
  • {S1.lower} — converts to lowercase

{C}

Replaced by your character name. Use it in any Pattern field to match lines that include your own name, and in any output field to speak or display your name.

{S}, {Sx}

Acts as a wildcard that captures any text, including multiple words. The captured value can then be used in any output field. Requires Regex to be enabled — the parser internally expands {S1} to (?<s1>.+).

Example: a Pattern of {S1} begins casting Malo captures the caster's name and you can speak {S1} is casting Malo.

{N}, {Nx}

Like {S} but captures a single number (no spaces). Useful for capturing damage values, spell durations, or HP amounts from the log line.

{N>y}, {y<N<z}

Works like {N} but adds a range check — the trigger only fires if the captured number satisfies the condition. Use operators >, <, >=, <=, or ==. Combine conditions with |.

Example: {100<=N<=500} fires only when the number is between 100 and 500 inclusive.

{L}

Replaced by the full log line that triggered the event (minus the date/time prefix). Useful for debugging — add it to Text to Display to see exactly what line fired the trigger. Available only in Text to Display, Text to Speak, and Alternate Timer Name.

{LOGTIME}

Replaced by the timestamp from the triggering log line in hh:mm:ss format. Available in Text to Display, Text to Speak, Text to Send, and Alternate Timer Name.

{REPEATED}

Replaced by the number of times the trigger has fired with the same captured values. The count resets after 750 ms (configurable via Repeated Reset Time on the trigger). Available in Text to Display, Text to Speak, and Alternate Timer Name.

Example: {S1} hit {repeated}x prints how many times the same source triggered.

{COUNTER}

Similar to {REPEATED} but counts total firings regardless of what values were captured. Also uses Repeated Reset Time to determine when the count resets.

{TS}

Captures a timestamp in hh:mm:ss format or a plain number of seconds from the log line, and uses it as the Timer Duration. Requires Regex to be enabled. Used to set a timer dynamically from a value in the log line itself.

{NULL}

When placed in any display or speak field, suppresses the output entirely. Useful for overriding a Timer End Early action when you want the timer to stop silently without speaking or displaying anything.

{TIMER-WARN-TIME-VALUE}

Replaced by the value configured in the trigger's Warn With Time Remaining setting. Lets your warning message reference its own configuration value.

{EQLP:STOP}

Not a variable — this is a command you send in-game (via /say, /group, /raid, or a custom channel). When EQLogParser sees a line starting with {EQLP:STOP} from your own character, it removes all running timers, speech, and overlays — the same as clicking the Stop button in the Trigger Manager. Only responds to lines originating from you.
