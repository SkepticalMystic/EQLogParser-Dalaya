Using the Parser

Navigating the main window and reading your combat data.

Main window layout

After loading a log file, the main window has three main areas:

  • Toolbar — buttons for opening a log file, accessing Settings, opening the Trigger Manager, and launching overlay windows
  • Fight list — a panel listing all the NPC encounters captured in the current session; each named NPC becomes its own fight entry
  • Content tabs — the main analysis area with tabs for Damage, Healing, Tanking, Spell Counts, Deaths, Loot, and other views; the selected tab updates to reflect the fight(s) you have chosen in the fight list

Fights and encounters

The parser groups combat events into fights automatically. A new fight begins when damage is first recorded against a named NPC, and the fight ends after combat activity stops. Each fight appears in the fight list with the NPC's name.

Unnamed adds or pets that deal or receive damage during a named encounter are included in that encounter's totals. If damage happens outside any named encounter — such as during a pull or against trash with no distinct name — it may appear under a generic entry.

Start a new parse session before each significant encounter by using File → New Parse (or the equivalent toolbar button). This clears old fights from the list so the data stays focused.

Live tailing vs. opening a log file

There are two ways to read a log file:

  • Live tailing — click the folder icon in the toolbar and select your log file. The parser watches for new lines as EverQuest writes them. Only events that happen after you select the file are captured.
  • Open from beginning — use File → Open Log File to read the entire file from the start. Use this to review a session you played earlier, or to catch fights that happened before you opened the parser.

Selecting fights

Click a fight in the fight list to view its stats. The content tabs update immediately. To view aggregated stats across multiple fights:

  • Ctrl+click to select individual fights to combine
  • Shift+click to select a contiguous range
  • Use the Select All option (right-click the fight list) to aggregate the entire session

When multiple fights are selected, all tabs show combined totals for that set.

The DPS Summary tab

The Damage tab shows a summary table with one row per player (and per pet, if unassigned). Common columns include:

  • Name — player or pet name
  • Total — total damage dealt across the selected fight(s)
  • DPS — damage per second over the fight duration
  • % — share of total group or raid damage
  • Hits / Avg — number of hits and average hit size
  • Crits — number and percentage of critical hits

Click any column header to sort by that column.

Damage breakdowns

Right-click any player row to open a per-spell breakdown showing how much damage each of their spells or combat abilities contributed. Right-click the fight (NPC) row to see a breakdown by attacker.

Double-clicking a row, or using the right-click menu's breakdown option, opens a detail window with hit distribution, damage ranges, and additional stats for that player.

Other tabs

  • Healing — heals cast and received per player; right-click for per-spell breakdown and access to the HoT Effectiveness table for HoT spells
  • Tanking — incoming damage per player, useful for tracking who is taking the most damage and from what sources
  • Spell Counts — how many times each spell was cast per player; right-click a spell for details or to open the Spell Details popup
  • Deaths — a log of player deaths with the last several hits before each death
  • Loot — items seen in loot messages during the session

Pet handling

Pets appear as their own rows in the DPS Summary until their owner is known. The parser learns ownership three ways, in priority order:

  1. petmapping.txt — a file in the app's data folder where you can pre-assign pet names to owners; loaded at startup
  2. In-game pet announcement — pets that say "My leader is X" in group chat are automatically assigned to that player
  3. Pet Owners UI — accessible from the right-click menu on any pet row; lets you manually assign a pet to a player for the current session

Once ownership is established, the pet's damage is folded into the owner's row and the pet appears as a sub-entry beneath them.

Dalaya's named pets are detected automatically by this fork and are never auto-assigned to your character name in raid logs. Ownership still needs to be confirmed via one of the three methods above.
