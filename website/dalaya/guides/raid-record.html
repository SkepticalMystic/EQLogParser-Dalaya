Raid Recording

Capture a combat-only log snapshot and deliver it automatically when the raid ends.

Raid Recording lets you bookmark the start and end of a raid session. When you stop the recording, EQLogParser extracts only the combat lines from that window — no chat, no system messages — and either saves them to a file or sends them directly to a Discord channel via webhook.

This is the fastest way to get everyone's logs to the raid leader for a Raid DPS merge. Instead of locating and uploading your full log file after the raid, each player clicks two buttons and the combat snapshot is delivered automatically.

First-time setup

Before recording, choose how the output will be delivered. Open Options > Raid Recording Settings, or right-click the Record button in the sidebar.

Two delivery modes are available:

  • Save to File — when you stop recording, a Save dialog opens and you choose where to save the file. The file is named eqlog_RaidRecord_YYYY-MM-DD_HHmmss.txt.
  • Send to Discord via Webhook — when you stop recording, the file is uploaded directly to a Discord channel using a webhook URL you provide. No Save dialog appears.

If you choose Discord, paste your webhook URL into the text box and click Test to verify the connection before the raid starts. The test sends a short text message to the channel; no log data is included.

To create a Discord webhook: open the channel you want to post to, go to Edit Channel > Integrations > Webhooks > New Webhook, copy the URL, and paste it into the setup window.

Your delivery preference and webhook URL are saved automatically. You only need to set this up once — it persists across sessions.

Starting a recording

Click the Record button in the left sidebar (the circle icon below Open Log). The button turns red and its tooltip shows the time recording started. The sidebar Record button is only visible when a log file is open.

If no delivery mode has been configured yet, the Setup window opens automatically on the first click so you can choose one before recording begins.

Start the recording at the beginning of the raid, before the first pull. Only events that occur after you click Record are captured.

Stopping a recording

Click the red Record button again to stop. EQLogParser reads the log from the point where you started, strips out all non-combat lines, and delivers the result according to your configured mode.

  • Save to File: a Save dialog opens. Choose a location and save.
  • Send to Discord: the file is uploaded in the background. A confirmation message appears when the upload completes.

If no combat lines were captured in the recording window (for example, you stopped immediately after starting), a message appears and nothing is saved or sent.

Size limit

Discord's file upload cap is 8 MB for most servers. Raid Recording monitors the size of captured combat data in the background and stops automatically if it exceeds 7 MB, leaving a margin below Discord's limit. A message appears when this happens.

For very long raids, consider starting a new recording after each major event (e.g., after clearing a zone wing) rather than running a single recording for the entire night.

Switching logs or closing the app while recording

If you open a different log file while a recording is active, EQLogParser will ask whether you want to save or send the recording before switching. Choosing No discards the current recording.

Similarly, closing the app while recording is active shows a warning. Clicking Yes closes the app and discards the recording; clicking No cancels the close so you can stop the recording first.
