Exporting for Raid DPS

How to share your log file so it can be merged with others.

The Raid Damage window combines raw log files from multiple players to build a complete, cross-player view of a raid encounter. There is no special export step — what you share is your EverQuest log file directly.

Before the raid: make sure logging is on

Logging must be active for the entire raid session to capture all events. If you miss the start of a fight because logging wasn't enabled, those events can't be recovered.

  • Type /log on in-game before the raid begins
  • Or set Log=TRUE in eqclient.ini to enable it automatically every session

See the Installation guide for more detail on enabling logging.

Finding your log file

Your log file is in the Logs subfolder of your EverQuest installation:

[EQ folder]\Logs\eqlog_CharacterName_eqemu.txt

The filename includes your character name and the server identifier (eqemu for Dalaya). For example: 

C:\Sony\EverQuest\Logs\eqlog_Kateila_eqemu.txt

In Windows Explorer, navigate to your EQ folder, open the Logs folder, and sort by Date Modified to find your most recent log file quickly.

Sharing your log file

Copy the log file and share it with whoever is running the Raid Damage merge — typically the raid leader or a designated parser. Any file transfer method works: Discord, a shared folder, direct message, etc.

Consider renaming the file to include your character name before sharing, since all Dalaya log files have the same filename format: 

eqlog_Kateila_eqemu.txt  →  Kateila_2026-06-15.txt

This makes it easier for the person loading multiple logs to keep track of whose file is whose.

What data is in the log

Your log file contains everything EverQuest wrote during your session — combat events, chat, system messages, and more. The Raid Damage window reads only the combat-relevant lines; the rest is ignored.

Only events your client witnessed are in your log. If a player was out of range when a damage proc fired, that event won't appear in their log. This is why combining logs from multiple players gives a more complete picture than any single log alone.

Archiving your logs

EverQuest appends to the same log file across multiple sessions. Over time this file grows large and older content can be harder to locate. A few options:

  • After each raid, copy the current log to an archive folder with a dated name before the next session starts appending to it
  • Use EQLogParser's built-in Log Backup utility (in the Tools menu) to automate periodic log archiving
  • Clear or rename the log file between raids to keep each session cleanly separated — EverQuest creates a new file automatically if the old one is missing
