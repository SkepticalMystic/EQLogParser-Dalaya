Creating Triggers

Audio alerts, timers, and overlays that react to your combat log.

Triggers watch your EverQuest log in real time. When a line matches a trigger's pattern, it fires: speaking a text-to-speech alert, displaying a message in an overlay, starting a countdown timer, playing a sound, or any combination of these.

Opening the Trigger Manager

Click the Trigger Manager button in the toolbar, or open it from the main menu. It opens as a panel or separate window with a folder tree on the left and the trigger editor on the right.

Organizing triggers into folders

All triggers live inside folders. Folders let you group related triggers and enable or disable entire categories at once. Create a folder structure that matches how you think about your triggers — for example, by content area, character, or trigger type.

  1. Right-click in the folder tree and choose New Folder
  2. Give it a descriptive name (e.g., "Mob AEs", "Buff Timers", "Procs")
  3. Folders can be nested — create sub-folders inside folders for finer organization

The checkbox next to each folder enables or disables all triggers inside it. Disabling a folder is useful when switching characters or content areas.

Creating a trigger

  1. Select the folder where the trigger should live
  2. Right-click and choose New Trigger, or click the Add button
  3. Give the trigger a clear name
  4. Enter a Pattern — the text the parser looks for in your log
  5. Check Regex if your pattern uses regular expression syntax (recommended)
  6. Fill in at least one action field (Text to Speak, Text to Display, Timer, or Sound)
  7. Click Save

Name triggers specifically enough that you can tell what they do at a glance in the Trigger Log — "Malo Landing" is better than "Spell trigger 3".

Writing patterns

The Pattern field matches against the content of each log line, after the date/time prefix is stripped. The match is case-sensitive by default.

A good pattern is specific enough not to fire on unrelated lines, but not so rigid that small log variations break it. For example, to catch a Darkness spell landing: 

You feel darkness creep over you\.

The \. escapes the period so it matches a literal dot, not any character.

Use trigger variables to capture values from the line and reuse them in your alert: 

{S1} begins casting Malo on {S2}\.

Then speak: {S1} is Maloing {S2} — the captured names are substituted in. See the Trigger Variables and Regex Reference guides for full syntax.

Using the spell picker

Rather than typing spell names manually, right-click the Pattern field to open the Spell Picker. It lists the full Dalaya spell database with search and filtering by class or spell type.

  • Find the spell you want and click Insert to paste its log text into the pattern
  • For buff spells with a known duration, click Generate Timer Bundle to create a complete set of triggers — cast, landing, and timer — automatically
  • For a whole category of spells (e.g., all Necromancer DoTs), use Generate Alternation to produce a single pattern that matches any spell in that group

Action types

Text to Speak

Spoken aloud by the text-to-speech engine when the trigger fires. Keep it short and clear — one or two words is often enough for an audio cue you'll be processing mid-combat. You can use trigger variables here: {S1} is casting.

Text to Display

Shown in an overlay window over the game. Useful for longer messages or when you want a visual cue alongside (or instead of) audio.

Timer

Starts a visible countdown bar when the trigger fires. Set the duration in seconds. The timer appears in the overlay window you've configured. Common uses:

  • Buff durations — the timer counts down to when you need to re-cast
  • Mob AE cooldowns — know when the next AE is coming
  • Recast windows — track spell cooldowns

Use {TS} in the Pattern to capture a duration from the log line itself and apply it dynamically as the timer length.

End Early Pattern

A second pattern that cancels a running timer before it expires. Use this for spells that can be resisted, absorbed, or removed early — the timer stops cleanly rather than counting down to zero on a buff that's already gone.

Sound

Plays an audio file when the trigger fires. Useful as an alternative to TTS for short, distinct alert sounds. Point the trigger at a .wav or .mp3 file on your system.

Testing triggers

Use the Test Trigger button in the trigger editor to simulate a log line matching the pattern. This lets you verify the TTS text, check that variables are captured correctly, and confirm that timer durations look right — without having to recreate the in-game event.

The Trigger Log tab (in the main window) records every trigger that fires in real time, showing the trigger name, the line that matched, and the time. Selecting a row in the Trigger Log highlights the corresponding trigger in the Trigger Manager, making it easy to jump to a trigger from its firing event.

Sharing and importing triggers

Triggers can be exported to a file and shared with other players, or imported from a file someone else has created. Use the right-click menu on a folder in the Trigger Manager to access import and export options.

Imported triggers replace or merge with your existing configuration. Review imports before enabling them, especially pattern fields, to make sure they match the exact log format for Dalaya's EQEmu server.
